# A-general-feedback-mechanism-unifying-stochasticity-long-transients-and-resilience
MATLAB code for the paper
# A General Feedback Mechanism Unifying Stochasticity, Long Transients, and Resilience

This repository contains the MATLAB code associated with the manuscript by Misha Chai and Holger Kantz, Max Planck Institute for the Physics of Complex Systems, Dresden, Germany.

## Overview

The code accompanies our study of a general feedback mechanism unifying stochasticity, long transients, and resilience.

## Code Description

The MATLAB files are organized according to the figures presented in the manuscript.

### Main Figures
- `Fig1.m` — Fig 1.
- `Fig2.m` — Fig 2.
- `Fig3.m` — Fig 3.
- `Fig4.m` — Fig 4.
- `Fig5_And_Fig6.m` — Fig 5 and Fig 6.

### Additional Calculations for Fig 5 and Fig 6

- `Fig5_a_UpperPanel.m` — Lifetime calculations for different values of the parameter \(a\), corresponding to the upper panel of Fig 5.
- `Fig5_a_BottomPanel.m` — Lifetime calculations for different values of the parameter \(a\), corresponding to the bottom panel of Fig 5.

- `Fig6_a_Small.m` — Lifetime calculations for different values of the parameter $a \in (0.0053, 0.0059)$, corresponding to Fig 6.
- `Fig6_a_Big.m` — Lifetime calculations for different values of the parameter $a \in (0.006, 0.01)$, corresponding to Fig 6.

### Supplementary Information

- `Supplementary_Fig1.m` — Supplementary Fig 1.

### Supporting Functions

- `plot_a1.m`
- `plot_a2.m`
- `plot_a3.m`
- `plot_a4.m`
- `plot_a5.m`

These files provide supporting functions used by the main MATLAB scripts.

## Requirements

MATLAB. The software version and any required toolboxes should be specified here.

## Usage

Run the corresponding MATLAB scripts to reproduce the numerical results presented in the manuscript. Keep the supporting function files in the MATLAB working directory or on the MATLAB search path.

Model parameters and numerical settings should be checked in the individual scripts.
